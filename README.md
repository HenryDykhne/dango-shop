# Dango Shop (Prototype)

Run the prototype with Python and pygame installed.

Install dependencies:

```bash
pip install -r requirements.txt --break-system-packages
```

Run:

```bash
python3 -m dango.main
```

This creates a minimal scene flow and the basic class structure described in architecture.md.
